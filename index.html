Task Allocation following simple Iterative Allocation algorithm. From a Task Graph that manages the precedence and characteristics of each Task, the algorithm assigns a robot for each one and builds the schedule to execute the mission. The schedule is computed pre-flight, so the actual flight usually differs from the planned schedule. Task can be Single or Multi-Robot.

System Architecture

Key Features

  • Consensus node capable of executing line, triangle or square formations for Multi-Robot Tasks
  • Single-Robot Tasks navigate to goal: surveillance/exploration Tasks
  • Navigate to Goal for each Task simultaneous to formation
  • Planned synchronization for Multi-Robot Tasks
  • Task Allocation based on bidding using makespan = distance_to_location + duration_of_task

Warehouse Surveillance

Warehouse surveillance system designed for autonomous security robots using RGB camera for real-time person detection, multi-object tracking, and ArUco markers verification. The robot follows a person until verified authorization.

System Architecture

Key Features

  • Pre-trained YOLOv8n for lightweight real-time person detection
  • ByteTrack algorithm for multi-object tracking with temporal ID persistence
  • ArUco marker verification based on the person's chest Region of Interest (ROI)
  • Reactive controller prioritizes closest unauthorized person as the largest unauthorized bounding box
  • Angular and linear speeds adjust proportionally to bounding box's location and area to ensure the followed person always stays in frame

Back Tracking Coverage

Implementation of online surface coverage algorithm using a BackTracking algorithm to visit all reachable areas with clearance distance to walls.

System Architecture

Key Features

  • Online lidar measurements
  • Spiral-like movement patterns
  • BackTracking Points (world coordinates) to cover missing areas
  • Rapidly exploring Random Tree (RRT) algorithm to compute paths from the robot’s current position to BackTracking Points
  • Straight line path enhancement for continuous trajectories

Mobile Manipulator Kinematic Control

Implementation of a Task-Priority Kinematic Control algorithm for Turtlebot with a mounted manipulator of 6 degrees of freedom (DoF), equipped with a vacuum gripper for pick-and-place tasks.

Key Features

  • Task-Priority control architecture
  • Combined forward kinematics of 6-DoF manipulator with mobile base
  • Implemented tasks:
    • Joint Limits
    • End-Effector Position
    • End-Effector Orientation
    • Mobile Base Position
    • Joint Position
  • Behavior tree for the pick and place task execution

Event-based Marine Snow Detection in Stonefish

Marine snow (suspended organic particles that interfere with underwater visual processing) segmentation using Event Based Cameras (EBCs) and Spiking Neural Networks (SNNs) through the Stonefish simulator.

Results

Key Features

  • Extensive simulated scenarios in Stonefish
  • eWiz library augmentation for marine snow segmentation
  • ConvGRU model trained using MSE loss for pixel-wise segmentation
  • Introduced custom metric for deeper explanation than Precision and Recall
    • MEPE: Mean EndPoint Error per blob in the image. It represents how far away (Euclidean distance) is a predicted blob to the closest from the ground truth
  • Future model tuning
