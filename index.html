Feature-Based EKF SLAM

Feature-Based Extended Kalman Filter SLAM for Turtlebot differential-drive robots using wheel odometry, IMU measurements, and ArUco landmark observations.

System Architecture

Results

Key Features

  • 2D point features map creation
  • ArUco id with Mahalanobis-distance data association
  • Simulation and real robot validation
  • Decreasing uncertainty of features and robot localization upon observation

Back Tracking Coverage

Implementation of online surface coverage algorithm using a BackTracking algorithm to visit all reachable areas with clearance distance to walls.

System Architecture

Key Features

  • Online lidar measurements
  • Spiral-like movement patterns
  • BackTracking Points (world coordinates) to cover missing areas
  • Rapidly exploring Random Tree (RRT) algorithm to compute paths from the robot’s current position to BackTracking Points
  • Straight line path enhancement for continuous trajectories

Mobile Manipulator Kinematic Control

Implementation of a Task-Priority Kinematic Control algorithm for Turtlebot with a mounted manipulator of 6 degrees of freedom (DoF), equipped with a vacuum gripper for pick-and-place tasks.

Key Features

  • Task-Priority control architecture
  • Combined forward kinematics of 6-DoF manipulator with mobile base
  • Implemented tasks:
    • Joint Limits
    • End-Effector Position
    • End-Effector Orientation
    • Mobile Base Position
    • Joint Position
  • Behavior tree for the pick and place task execution

Event-based Marine Snow Detection in Stonefish

Marine snow (suspended organic particles that interfere with underwater visual processing) segmentation using Event Based Cameras (EBCs) and Spiking Neural Networks (SNNs) through the Stonefish simulator.

Results

Key Features

  • Extensive simulated scenarios in Stonefish
  • eWiz library augmentation for marine snow segmentation
  • ConvGRU model trained using MSE loss for pixel-wise segmentation
  • Introduced custom metric for deeper explanation than Precision and Recall
    • MEPE: Mean EndPoint Error per blob in the image. It represents how far away (Euclidean distance) is a predicted blob to the closest from the ground truth
  • Future model tuning
